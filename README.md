# 安享智慧理财 Postman 接口测试

本仓库保存“安享智慧理财”项目的 Postman 接口测试集合与测试环境配置，覆盖登录和个人信息修改两个功能域。

## 测试范围

- 登录：成功登录、未注册手机号、密码错误、连续输错密码、空值、长度边界和异常参数等场景。
- 修改个人信息：登录获取权限后，调用个人信息保存接口。

## 文件说明

| 路径 | 说明 |
| --- | --- |
| `安享智慧理财.postman_collection.json` | Postman 测试集合 |
| `测试环境.postman_environment.json` | Postman 环境变量 |
| `data/` | 数据驱动测试数据 |
| `report/` | Newman / Allure 生成的测试报告 |

## 使用方式

1. 在 Postman 中导入测试集合和环境文件。
2. 选择“测试环境”，按实际测试账号或令牌更新环境变量。
3. 在 Collection Runner 中执行集合；如需数据驱动测试，选择 `data/` 中相应数据文件。

也可以使用 Newman 命令行执行集合，并使用 Allure 生成可视化报告。

> 环境文件可能含测试令牌，仅用于受控测试环境；提交前请确认其中没有生产凭据。
